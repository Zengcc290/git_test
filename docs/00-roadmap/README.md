# RAG 学习路线

## 阶段 1：基础

掌握 Transformer/LLM 基本概念、文本表示、Embedding、余弦相似度、倒排索引和向量数据库。

产出：能解释“生成”和“检索”各自解决什么问题，并完成一次向量相似度搜索。

## 阶段 2：最小 RAG

完成文档加载、解析、切分、Embedding、建库、召回、上下文拼接和答案生成。

产出：`examples/01-minimal-rag/` 中可运行的端到端问答流程。

## 阶段 3：检索质量

比较不同 chunk 策略、Top-K、混合检索、Metadata Filter、Reranker 和查询改写。

产出：一组固定问题、检索命中率对比和误差分析记录。

## 阶段 4：生成质量

练习引用、拒答、上下文压缩、多轮对话和结构化输出，减少幻觉与无依据回答。

产出：可复用的提示词模板和生成评测结果。

## 阶段 5：评估与工程化

建立离线评测、追踪、缓存、版本管理、权限控制和成本监控。

产出：`docs/03-evaluation/` 与 `docs/04-production/` 中的设计记录。
