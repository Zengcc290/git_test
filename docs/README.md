# 文档与学习资料

这里存放 RAG 学习过程中可长期复用的资料。按编号从基础到工程化排列：

- `00-roadmap/`：学习路线、阶段目标和检查清单
- `01-foundations/`：LLM、信息检索、Embedding、向量数据库基础
- `02-rag-pipeline/`：RAG 数据流各阶段的原理与设计
- `03-evaluation/`：评测集、指标、误差分析和质量门禁
- `04-production/`：架构、部署、可观测性和成本控制
- `05-references/`：论文、官方文档和外部文章
- `06-notes/`：个人概念笔记、阅读记录和问题排查

建议一篇资料只放一个主目录；跨主题内容在文档中用链接关联，避免复制多份。
